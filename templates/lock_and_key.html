Lock & Key Memory Game

Directional Doors: Some doors only open from one side!

Level 1 (3x3) - Find Key!

Attempts: 0
🎮

Game Rules & Information:

  • Start at the dark square (👤).
  • Invisible walls/barriers are randomly generated on each board and never touch each other.
  • Hitting an invisible wall flashes red and bounces you back to the start! Use your memory to remember where walls are.
  • Collect the key 🔑 first, then make your way to the exit door 🚪.
  • Click 🎲 New Board to play a new randomized layout anytime!
